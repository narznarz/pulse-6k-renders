# Pulse 6K Renders

Pulse 6K 렌더 이미지 번들입니다. 다운로드 후 압축을 풀어 사용하세요.

## 파일

- `pulse_6k_avif.zip` (약 42 MB) — AVIF 포맷 렌더 번들
- `pulse_6k_jpg.zip` (약 14 MB) — JPG 포맷 렌더 번들

## 다운로드

GitHub 저장소 페이지의 **Code → Download ZIP**으로 전체를 받거나, 개별 파일을 클릭해 **Download raw file**로 받을 수 있습니다.
